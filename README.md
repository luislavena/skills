# Skills

A curated collection of specialized skills, designed to enhance
AI-assisted workflows with structured methodologies and proven techniques.

This repository contains skills that can be cloned and used to provide
domain-specific guidance for tasks like idea validation, requirements analysis,
and critical thinking.

## Available skills

### Idea validator

A critical-thinking brainstorming partner that acts as a requirements analyst.
Challenges assumptions, questions perceived problems, and ensures solutions
address genuine needs before exploring implementation.

**Triggers on:** "I want to build", "help me validate", "users need",
"I'm thinking of creating"

**Includes:**

- Structured questioning process (6 phases)
- Anti-pattern detection (15+ common traps)

[View full documentation](skills/idea-validator/SKILL.md)

## Contribution policy

Inspired by [Litestream](https://github.com/benbjohnson/litestream) and

burden so they will not be accepted at this time. Please
[submit an issue](https://github.com/luislavena/skills/issues/new) if you have
a feature you would like to request or discuss.
